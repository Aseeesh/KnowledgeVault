# KnowledgeVault Web Client

Frontend application for the KnowledgeVault platform. Provides a search interface for querying documents and managing the knowledge base.

## Tech Stack

- **Framework**: React 19 with TypeScript
- **Build Tool**: Vite 6
- **Styling**: Tailwind CSS
- **Data Fetching**: TanStack React Query
- **Routing**: React Router v7
- **Icons**: Lucide React

## Running Locally

```bash
npm install
npm run dev
```

App available at `http://localhost:5173`

## Pages

- **Search** (`/`) — Hybrid search with AI-generated answers
- **Documents** (`/documents`) — Document management and upload
